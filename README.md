# Instagram Clone (Flutter)
A simple Instagram clone app built using Flutter (Dart). This project replicates some of the core features of Instagram such as user authentication, photo upload, feed, likes, and comments.

# Features
- User authentication (Sign up, Login, Logout)
- Like & Comment on posts
- User profile page (with posts, followers, following)

# Tech Stack
- Frontend: Flutter (Dart)
- Backend: Firebase 

# Installation & Setup
- Clone the repository
git clone https://github.com/NandiniV-20/Instagram-App.git
cd Instagram-App

- Install dependencies
flutter pub get

- Run the app
flutter run

-Add your google-services.json (Android) and GoogleService-Info.plist (iOS).
